# 梦婷输入法（MengtingIME）

纯原生 Kotlin 安卓输入法，无第三方输入法 SDK。

## 特性（v1.0.1）

- 全键盘 / 九宫格 / 符号 / 表情多布局，中英切换
- 自研拼音引擎：全拼、九宫格数字串、模糊音、词组切分，114 万高频词 + 2 万字音表内置
- 长按空格：本地离线语音转文字（sherpa-onnx 流式 zipformer 中英模型，内置约 190MB）
- 长按删除 + 左滑：全删输入框内容
- 长按中英键：全局翻译当前输入框文本
- 长按句号：屏幕取字（MediaProjection 截屏 + MLKit 中文 OCR），点选复制并回填
- 四套像素风动态键盘背景，按北京时间自动切换（6-16:59 太阳蓝天 / 17-18:59 夕阳火烧云 / 19-0:59 月亮夜空 / 1-5:59 流星满天星）
- 按键颜色自定义、背景图片自定义上传（未上传时用时间动态背景）
- 清脆按键音效：走通知铃声通道，免打扰自动屏蔽
- 单手模式：键盘纵向拉长横向收窄，重力感应定偏向，可设默认侧与逆转
- 横屏自适应：游戏场景可用"小而美"悬浮键盘（可拖拽、可缩放）
- 桌面小组件：今日码字数 + 情绪占比，每天凌晨 5 点刷新
- 应用内检测更新：对比本仓库最新发布版本号，下载 APK 引导安装
- 开屏动画：图标 9:16 → MT 浮现 → 烟雾化 → 竖排「梦婷输入法」
- 首次启动引导启用并设为系统默认输入法

## 版本规则

初始版本 1.0.1；每次优化末位 +1。发版同步打 tag 并发布含 APK 的 Release。

## 构建

- JDK 17 / Gradle 8.7 / AGP 8.5.2 / compileSdk 34 / minSdk 24
- `gradle assembleDebug` 或 `assembleRelease`
